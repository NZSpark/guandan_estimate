## 改动流程

1. 先改文档（或与用户确认以文档为准），再改 `HandScorer`，最后改测试。顺序不可颠倒。
2. 在 `app/src/test/.../scoring/` 补断言：至少覆盖**改动点本身**和**相邻边界**（如 191/192、5 炸/同花顺、火箭 1000）。
3. 同步 `README.md` 的「牌力指标」节（公式、上限、阈值表）。
4. 全量 `./gradlew testDebugUnitTest`；若评级展示变化，跑 `assembleDebug` 手验。
5. 写回 `harness/state.md`，必要时追加 `DECISIONS.md` 记录规则版本变更。

## 已知不变量（改动前必须确认仍成立）

- 普通牌型映射上界 191；最小四炸 192；火箭固定 1000。
- 大小关系链：普通 < 4炸 < 5炸 < 同花顺 < 6炸 < … < 火箭（以文档表为准）。
- 6 张及以上炸弹走对数平滑，不得写成线性。
- 炸弹内的红心配只按替代点数计，与同点数自然炸弹同分，不得按 15 抬分（三张5+配 210 < 四张6 216）。
- 级牌对子/三张的候选分必须走 `pairScore` / `tripleScore`（`baseValue`）：自然级牌与用于级牌自身的红心配按 15；红心配替代非级牌按替代点数。
- 6~9 炸公式常数固定为 `523+55·log`、`577+73·log`、`672+75·log`、`784+66·log`；4/5/10 炸不变。V4.2 不改炸弹常数。
- 9/10 炸的 810/912 是**跨级牌局的全局最小值**；级牌为 2 时有效最低构成是 8 张 3 + 配（821/922）。断言最小值时必须写明所设级牌。
- `α=1.15` 仅适用于炸弹、同花顺、火箭、单张大王、单张级牌。
- `P = 15 × N_waste`，`N_waste` 只数点数 <10 且无法成牌的孤立单张/小对子；`P` 对 **1～27 张统一适用**，残局不再豁免（综合评估 §4.3 / 示例 2）。
- 19～26 张与 10～12 张不输出正式评级（`grade` 返回「待标定」）；残局 `R_control = N_control/(T_plan-1)` 仅在 `T_plan≥2` 时计算，`T_plan=1` 返回 `null`。
- 三带二对子可为小王对/大王对，但红心配不得替代王；王对只取实体牌。
- 拆牌搜索是 anytime：`exhaustive=true` 才是全局最优，`false` 只能标注「近似最优」；不得恢复「达到状态上限后剩余牌全按单张」的旧退路。

## 易错点

1. **级牌取值随牌型变化**：单/对/三按 15（含用于级牌自身的红心配）；炸弹的自然级牌按 15、红心配按替代点数（三张5+配 = 四张5 = 210）；顺子与同花顺按使 Sum 最大的填法，且 `V_max` 取实际最大自然牌，A2345 中 A 记 1、10JQKA 中 A 记 14；连对/钢板按替代点数且最多 6 张；三带二的自然级牌按 15，红心配替代非级牌时按替代点数（替代级牌时按 15），映射区间 **`16..109 → 50..191`**（V4.2 已落地，`222+AA` 回落为 182）。
2. **A 的双重值**：A 通用 14，但在 A2345 顺子中记 1。
3. **`T_plan` vs `T_max(N)`**：SPI 分母是拆牌方案的计划轮数，NSPI 分母是当前张数的理论上限，两者不可混用。
4. **四舍五入**：线性插值结果四舍五入取整，测试断言用整数而非浮点近似。
5. 现有测试文件按场景拆分（`Case2Test`、`Case3Test`、`ScoringV4Test`、`DynamicHandEvaluationTest` 等），新用例优先并入语义最接近的文件，避免碎片化。
