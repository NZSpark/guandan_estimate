# Archive —— 过期知识归档

本目录保存**不再需要频繁加载、但仍有参考价值**的内容。

## 规则

1. 只归档，不删除（见 `DECISIONS.md` ADR-0004）。
2. 每个归档文件必须在开头写：

   ```markdown
   > ARCHIVED YYYY-MM
   > 原因：<被谁/什么取代>
   > 原位置：<原路径>
   ```

3. 文件名格式：`<原文件名>-<YYYY-MM>.md`，例如 `scoring-rules-2026-10.md`。
4. 归档内容默认**不参与**任何路由；需要时手动读取。
5. `DECISIONS.md` 的历史条目本身不归档（保持单一时间线）；仅当条目数量膨胀时，可把已被取代的整段移入 `decisions-<YYYY>.md` 并在此登记。
